# Thiết kế xe tự hành tránh vật cản sử dụng ESP32

## Thành viên
- Nguyễn Khắc Thuận An
- Nguyễn Văn Dương
- Trần Văn Báu

## Giới thiệu
Xe bốn bánh sử dụng ESP32, cảm biến HC-SR04, servo SG90 và module L298N.
Chương trình MicroPython điều khiển xe theo năm trạng thái: DRIVE, SCAN, TURN, BACK và SAFE.
